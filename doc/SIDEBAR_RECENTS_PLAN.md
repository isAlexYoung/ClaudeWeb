# 左侧栏「最近使用」改版 — 动工文件

> 基线：2.3.5（`3bd8420`）。只改左侧栏的会话区域；页面入口（新建聊天、搜索、作品、定时任务、插件）不动。

## 1. 要做什么

### Chat 模式
- 不再显示「Chats」列表，只保留「置顶」（只含 Chat 的会话）、用户建的**分区**和**最近使用**。
- 「最近使用」只含 Chat 和作品的会话；Code 的项目会话不再出现在这里（两边互不相通）。
- 会话行前面不再有图标（聊天气泡、作品、定时任务时钟都去掉）；作品会话在行尾用浅色的类型小图标标出（参考图 2 的「未命名」）。
- 筛选后没有会话时，「最近使用」列表留空，不显示占位文字（与原来的侧栏一致）。
- 「最近使用」标题行：左边「最近使用 ⌄」点一下收起 / 展开整个最近列表；右边是筛选按钮，菜单如下（与图 3–7 一致，「所有者」不做）：

| 项 | 选项 | 默认 |
|---|---|---|
| 状态 | 活跃 / 已归档 / 全部 | 活跃 |
| 最近活动时间 | 1 天 / 3 天 / 7 天 / 30 天 / 全部时间 | 全部时间 |
| 定时任务 | 已显示 / 分组显示 / 已隐藏 | 已显示 |
| 分组依据 | 日期 / 未读 / 状态 / 无 | 无 |
| 排序方式 | 名称 / 创建日期 / 最近活动时间 | 最近活动时间 |
| 新建分区 | 弹出命名框 | — |

- 分区（图 8）：建好的分区显示在「最近使用」上方，标题「aa ⌄」可单独收起，空分区显示「这里还没有内容」；分区标题的「…」可重命名、删除分区（删除后其中的会话回到最近使用）。
- 会话行改为悬停出现「…」菜单：置顶 / 取消置顶、重命名、移至分区 ›（列出分区、移出分区、新建分区…）、归档（已归档的会话显示「恢复」）、删除。放进分区的会话只在分区里显示，不在最近使用里重复。

### Code 模式
- 项目树不变；「最近使用」只含项目会话（不含 Chat 和作品）。
- 「置顶」只显示置顶的项目和项目会话。
- 会话行同样去掉前置图标；行上的悬停工具保持原样。
- 「最近使用」标题右侧的按钮只有「排序方式 ›」（图 9）：上次更新 / 创建日期 / 名称，降序 / 升序。分组依据、显示、新建部分、恢复默认、查看全部都不做。

## 2. 服务端

`GET /api/providers/sessions/recent` 增加可选参数（不传时与现在完全一样）：

- `scope=chat|project` 与 `chatPath`：chat = 会话目录等于 Chat 工作目录；project = 其余（含无目录的旧会话）。Chat 工作目录仍由前端的 `CHAT_WORKSPACE_PATH` 决定，作为参数传入，不在服务端再写一份。
- `status=active|archived|all`：活跃 = 会话与所属项目都未归档（现状）；已归档 = 会话已归档；全部 = 两者之和。
- `sinceDays=1..3650`：最近活动时间在 N 天内。
- `sort=activity|created|name` 与 `order=asc|desc`（名称不区分大小写，没有名字的按 id）。

返回的每一项增加 `createdAt`、`isArchived`。筛选和排序都在 SQL 里做，分页（每页 40）因此仍然连续、正确。

## 3. 前端

- `sidebarConversations` 用户偏好（与其他设置一样存服务端、跨设备同步）：
  `{ chat: { status, sinceDays, scheduled, groupBy, sort }, code: { sort, order }, sections: [{ id, name }], sessionSections: { [sessionId]: sectionId }, collapsed: { chatRecent, codeRecent, sections: { [id]: bool } } }`。
- `useSidebarController` 接收当前模式的查询条件，条件或模式变化时重新加载第一页。
- `conversationView.ts`（纯函数，可单测）：按日期（今天 / 昨天 / 过去 7 天 / 过去 30 天 / 更早）、未读（未读 / 已读）、状态（活跃 / 已归档）分组；定时任务「分组显示」时单独成组放在最后，「已隐藏」时过滤掉；分区成员从最近列表里移除。
- 未读：本机记录每个会话最后一次打开或离开的时间（localStorage，最多 500 条），最近活动晚于这个时间即为未读；第一次启用前的会话视为已读；正在后台完成、带提醒点的会话也算未读。
- 分区里不在当前已加载页里的会话，按 id 读一次会话详情补上标题（与置顶的处理方式相同）。
- 菜单沿用作品页 / 定时任务的 `ScheduledTaskMenu`（带二级菜单和勾选），外观与图 3–9 一致。
- 中、英、繁体文案。
