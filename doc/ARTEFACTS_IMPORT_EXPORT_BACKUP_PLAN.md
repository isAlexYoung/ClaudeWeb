# 作品：导入导出与备份 — 动工文件

> 基线版本：2.3.7（`a74f067`）。目标版本：2.3.8。
> 前置文档：`doc/ARTEFACTS_PLAN.md`（电子表格）、`doc/ARTEFACTS_DOC_WHITEBOARD_PLAN.md`（文档与白板）。本文只写新增与改动。

## 1. 要做什么

| 类型 | 导出（现状 → 本次） | 导入（本次新增） |
|---|---|---|
| 电子表格 | CSV（仅第一个工作表）→ **Excel（.xlsx，全部工作表）**、CSV（当前工作表） | .xlsx、.csv、.tsv |
| 文档 | Markdown → Markdown、**Word（.docx）**、**PDF**（浏览器打印「另存为 PDF」） | .md / .markdown、.txt、.docx |
| 白板 | PNG、.excalidraw → PNG、**SVG**、.excalidraw | .excalidraw（Excalidraw 官方 JSON，含 .json） |

另外：

- **备份与恢复包含作品**：导出的备份带上全部作品的文件与记录；恢复时一并还原，并重新连上已恢复的对话。
- 不做：幻灯片、设计、数据（仪表板）；旧版 .xls / .doc（二进制格式）；PDF 导入。

## 2. 入口

### 2.1 导入

- 作品页「+」菜单新增「导入文件…」，打开系统文件选择框，可多选。
- 把文件直接拖进作品页也能导入（页面显示一层「松开以导入」的提示）。
- 按扩展名决定类型，标题取文件名（去掉扩展名）。
- 只导入一个文件时直接打开它；多个时留在作品页，并提示「已导入 N 个作品」。
- 失败的文件（格式不支持、内容损坏、超过大小上限）逐个提示原因，不影响其他文件。

### 2.2 导出

- 编辑器标题菜单的「下载」改为子菜单，列出该类型的全部格式。
- 会话顶部作品卡片上的下载按钮改为点击弹出同样的格式菜单。

## 3. 实现

### 3.1 选型（全部在浏览器里转换，按需懒加载，不进主包）

| 用途 | 库 | 许可证 |
|---|---|---|
| .xlsx 读写 | ExcelJS 4.4 | MIT |
| .docx 导出 | docx 9.x | MIT |
| .docx 导入 | mammoth 1.x（docx → HTML） | BSD-2-Clause |
| 文档 Markdown ↔ 结构 / HTML | 已有 Tiptap（无界面 Editor，扩展与文档编辑器相同） | MIT |
| 白板 SVG / PNG | 已有 Excalidraw 的 `exportToSvg` / `exportToBlob` | MIT |

转换放在浏览器里：服务器只收发作品本身的格式（`claudeweb-sheet@1`、Markdown、Excalidraw JSON），校验与存储逻辑不变。

### 3.2 电子表格 ⇄ Excel

`transfer/sheetTransfer.ts`：

- 单元格：数字、文本、布尔原样；以 `=` 开头的写成公式。工作簿设置为打开时整本重算，让 Excel / WPS / LibreOffice 显示计算结果。
- 样式：粗体、斜体、下划线、文字色、填充色、水平 / 垂直对齐、字号、数字格式双向对应。
- 合并单元格、列宽（像素 ↔ Excel 字符宽度，按 7px / 字符）、行高（像素 ↔ 磅，×0.75）、冻结行列双向对应。
- 导入时：
  - 日期转成 Excel 序列号，并带上日期格式；Excel 内置的「短日期」（`mm-dd-yy`，各地显示顺序不同）改成 `yyyy-mm-dd`。
  - 主题色按 Office 默认主题配色（含明暗 tint）换成固定颜色，不再提示「主题色未导入」（几乎每个真实工作簿都会触发）。
  - 富文本合并成纯文本；超链接取显示文字。
  - 共享公式展开成各自的公式；错误值保留为文本。
- CSV / TSV 导入：
  - 自动识别分隔符（逗号、分号、制表符），处理引号与 BOM。
  - 形如数字的文本转成数字，但 `007` 这类以 0 开头的编号保留为文本；TRUE / FALSE 转成布尔。
  - 不是 UTF-8 的文件按 GBK 读（老的中文 CSV 多是 GBK）。

### 3.3 文档

`transfer/docTransfer.ts`：同一个无界面 Tiptap（与 `DocumentEditor` 共用扩展列表 `doc/docExtensions.ts`）负责：

- **导入 .docx**：mammoth 转成 HTML → 整理 → Tiptap 读入 → `getMarkdown()`。图片以内嵌数据保留；总大小超过文档上限（2 MB）时去掉图片并提示。整理包括：
  - Word 段落样式 `Code` / `HTML Preformatted` 读成代码块（换行保留，含空行），`Quote` / `Intense Quote` 读成引用。
  - 以 ☐ / ☒ 开头的连续段落还原成任务列表。
  - 表格没有标记表头行时，把第一行当表头（Markdown 表格必须有表头，否则会多出一行空表头）；整格加粗的表头去掉加粗。
- **导入 .md / .txt**：原样作为 Markdown。
- **导出 .docx**：Markdown → Tiptap JSON → docx 段落：
  - 支持标题 1–3、粗体、斜体、删除线、行内代码、链接。
  - 支持有序 / 无序 / 任务列表、引用、代码块、分隔线、表格、图片。
  - 代码块用 `Code` 段落样式、引用用 `Quote` 段落样式，表格第一行标记为 Word 表头行（跨页重复）；这样在 Word 里样式有名字，导回 ClaudeWeb 时也能还原成代码块、引用和表头。
- **导出 PDF**：Markdown → HTML，放进隐藏 iframe（自带打印样式，含中文字体回退），调用浏览器打印，由用户选「另存为 PDF」。不用 jsPDF：它要内嵌中文字体，体积大且排版差。

### 3.4 白板

- 导出 SVG：`exportToSvg`，背景色与作品一致。
- 导入 .excalidraw：解析 JSON，`type === "excalidraw"`，再按现有规则补齐元素（简写元素同样支持）。

### 3.5 服务端

- `POST /api/artefacts` 接受可选的 `content`：
  - 按类型的格式描述校验与大小限制，非法时返回 400，并带上原因。
  - 不给 `content` 时仍写入空白内容，行为不变。

### 3.6 备份与恢复

- 新增备份区域 `artefacts`（压缩包内路径 `claudeweb/artefacts/`），存放 `~/Artefacts` 下全部作品文件。
- 数据快照新增 `artefacts` 记录：
  - 字段：id、类型、标题、文件名、关联会话、置顶、创建 / 更新 / 打开时间。
  - 旧备份没有这一项，按空处理。
- 导出：始终包含作品（与 Claude 用户设置、上传文件一样，不需要勾选）。
- 恢复：
  - 预览里显示「作品：N 个（新 M 个）」，并提供「恢复作品」开关（默认开）。
  - 已存在同 id 的作品不覆盖，计入「已跳过」。
  - 新作品写到当前用户的 `~/Artefacts`，路径按新主目录重写。
  - 关联会话在恢复后存在则连上；不存在时留空，打开时会新建会话（现有逻辑）。
- 恢复结果里报告作品数量。

## 5. 风险

| 风险 | 对策 |
|---|---|
| 新库体积（ExcelJS 约 1 MB、mammoth 约 0.6 MB、docx 约 0.4 MB） | 只在导入 / 导出时动态加载 |
| Excel 有而作品格式没有的东西（图表、条件格式、数据验证、批注、图片） | 导入时忽略并提示「部分内容未导入」，单元格数据与基本样式保留 |
| 大文件超过作品上限（表格 5 MB、文档 2 MB、白板 10 MB） | 导入前检查，超出时明确提示，不建空作品 |
| 导出的公式没有缓存结果，有的预览器显示空白 | 设置打开时重算；Excel / WPS / LibreOffice 正常 |

## 6. 后续（本次不做，单独评估）

- **电子表格深色模式**：可以做。FortuneSheet 的画布颜色写死在渲染代码里（白底、黑字、浅灰网格），不能靠配置改。做法是只在深色主题下，对表格画布的绘制颜色做亮度反转映射：保留色相，深浅对调。这样默认的白底黑字变成深底浅字，用户设的颜色也保持对比度。文件里存的颜色和导出结果不变。公式栏、工作表标签、编辑框这些 DOM 部分另用样式覆盖。工作量中等。
- **在普通对话里让 Claude 生成作品**：
  - 需要给 Claude 加一个进程内工具（新建作品、取得文件路径与编辑说明）。
  - 一个对话要能关联多个作品，并按对话把各作品的编辑说明附给 Claude。
  - 对话记录里显示可点击的作品卡片，侧栏与最近使用要同步。
  - 工作量与 2.3.4（文档与白板）相当。
