# ClaudeWeb 独立版项目清单

日期：2026-11-20。阶段：需求整理，尚未实现产品代码或创建远程仓库。

目标是建立独立、开源、可一键安装的 ClaudeWeb，保留现有 ClaudeWeb 全部功能，整合必要的浏览器运行及安装更新能力，取消对 WebDesktop 和 fa-build 的运行依赖。

“已确认决策”的勾选表示需求已确定；实现任务的空框表示尚未完成开发或验收。

- [x] 安全模型采用单用户：Claude、终端与后台同为 `claudeweb` 用户；程序文件归 root，更新只接受签名安装包，sudo 密码不经过 Claude 可见的位置。
- [x] 浏览器优先稳定，首选 Playwright 提供的 Chromium（固定版本、各发行版一致）；不支持部分专有视频解码不作为问题。
- [x] 不提供一键导出所有数据；只保留现有设置中的导出数据功能。
- [x] 未配置域名时只监听本机地址，通过 SSH 隧道访问（与 CMCP 现有方式一致），不在公网 IP 上提供明文 HTTP。
- [x] 只使用 SQLite，不再安装和维护 PostgreSQL。
- [x] 不考虑 VPS 位于中国大陆的网络环境。
- [x] 不收集任何使用数据，不上报统计。
- [x] 接受外部贡献（PR）。
- [x] 域名通过 Cloudflare Tunnel 接入：服务始终只监听本机，VPS 不对公网开放端口。
- [x] 手机和平板访问需要配置域名；电脑可用 SSH 隧道或 CMCP。
- [x] 只新仓库搬迁测试代码，不搬迁历史测试记录、变更记录和内部报告；CHANGELOG 从 2.0.0 开始。

## 独立运行与权限

- [x] ClaudeWeb 自己提供登录、会话和退出；不提供网页注册或首次设置页面，避免他人抢先创建账号。（2026-11-20：只输一个密码，会话记录在服务器端）
- [ ] HTTP、WebSocket、终端、文件、浏览器和更新接口统一经过鉴权。
- [x] 移除对 WebDesktop 外层认证的依赖，不能把当前信任外层认证的平台模式直接暴露公网。（2026-11-20 已删除平台模式。2026-11-20 已换成自己的密码登录，上游注册页已删除。）
- [ ] 创建普通运行用户 `claudeweb`，统一 HOME、工作区和子进程环境。
- [ ] 统一项目、下载、配置的文件所有权和默认权限，减少跨用户协调。
- [ ] 安装程序和系统配置由安装器管理，应用不直接替换系统级程序文件。
- [ ] root 更新组件只执行已定义操作，不提供通用 root Shell 接口。
- [ ] 浏览器保留自身沙箱，不通过关闭内部沙箱强行统一身份。
- [ ] 说明多个会话共享运行用户和项目权限，不宣称每个聊天有独立沙箱。
- [ ] 将浏览器所需的最小图形运行和画面转发组件独立出来，由 ClaudeWeb 管理。
- [ ] 内置浏览器安装中文字体（如 Noto CJK），正常显示中文网页；保留浏览器内的中文输入（现有为 fcitx5）。
- [ ] 浏览器可在无物理显示器的 VPS 工作，不依赖 WebDesktop 网关或桌面界面。
- [ ] 不要求存在旧的 `wdterm`、`wdguest`、`wdsvc`、`wdgui`、WebDesktop 数据库或安装状态。

- [ ] 为未来图形应用扩展留出接口，本阶段不实现或安装 Claude Desktop，不显示不可用占位按钮。

- [ ] 支持 CMCP 现有的“通过 SSH 自建 ClaudeWeb”连接方式。
- [ ] 明确旧版 CMCP 连接独立版时的兼容范围和提示。
- [ ] CMCP 中的“CloudCLI”名称后续改为“ClaudeWeb”，属于 CMCP 项目，本项目暂不改动。

## 登录、多设备与密码

现有这部分功能由 WebDesktop 提供，独立版需要重新实现。

- [ ] 最多 3 台设备同时登录；已有设备登录时，新登录选择“加入”或“接管”，接管前再次确认，满 3 台时先选一台退出。
- [ ] 设置中的登录设备列表：设备类型、来源（网页、CMCP）、IP、时间，标出主设备和本机，可踢出其他设备。
- [ ] 新设备登录时提醒其他设备，可选“知道了”或“踢出”。
- [ ] 手动网页登录每台设备闲置 1 小时后退出，真实操作及忙碌的主会话续期，后台轮询不续期。
- [x] 退出登录只结束本设备，修改密码让所有设备退出。（已打开的 WebSocket 连接在下次重连时才断开，多设备一项再改为立即断开）
- [ ] 一键安装生成登录密码，在安装结束时输出。
- [x] root 命令查询当前登录密码（如 `claudeweb password`），密码保存在只有 root 可读的文件中。不考虑攻击者已取得 root 权限的情况。
- [x] root 命令修改登录密码（如 `claudeweb password --set`；`--set --stdin` 可自己输入，终端里不显示），修改后同步更新上述文件，查询到的始终是当前密码，并让所有设备退出。
- [ ] 密码验证失败限制按访问者 IP 分别计数：同一 IP 连续 5 次失败禁用 1 分钟，再 5 次禁用 5 分钟，再 5 次及之后每 5 次禁用 30 分钟；该 IP 登录成功后计数清零。页面显示剩余等待时间。CMCP 自动登录同样受此限制。通过域名或反向代理访问时，只采信自己的代理传来的真实 IP，避免伪造。（2026-11-20 网页登录已实现：只在本机连接上采信 Cloudflare 的 CF-Connecting-IP；24 小时没有再失败也会清零；CMCP 自动登录待第 5 项接入）

## sudo 授权

- [ ] Claude 或终端命令需要 sudo 时，在 ClaudeWeb 会话中弹出确认，显示要执行的命令；用户可输入 sudo 密码同意，也可拒绝。
- [ ] 密码只交给 sudo，不进入 Claude 上下文、对话记录、日志或浏览器存储，也不保存。
- [ ] 拒绝、超时或密码错误时命令失败并告知 Claude，不自动重试。
- [ ] 不配置无密码 sudo；安装时设置 `claudeweb` 用户的 sudo 密码，并提供修改命令。

## 敏感信息提示

- [ ] Claude 要读取或外发以下内容前，在会话中提示“此类内容为用户敏感信息”，用户确认后才继续，可拒绝：Claude 的登录凭据；内置浏览器的 Cookie 和登录数据；ClaudeWeb 数据库、登录密码文件和签名密钥。
- [ ] 敏感路径清单集中维护，覆盖文件读取、搜索和命令执行等工具调用。
- [ ] 说明提示的边界：只拦截能识别的访问，不能完全阻止同一用户下的程序读取；用户在终端中自己执行的命令不弹提示。

## Claude CLI

- [ ] 安装官方 Claude Code CLI，聊天（通过 Agent SDK 启动）与终端中的 `claude` 使用同一份程序和同一份登录信息。现有实现为 `/opt/claude-cli/.local/bin/claude`，由 `CLAUDE_CLI_PATH` 指定。
- [ ] 登录流程：在 ClaudeWeb 终端运行 `claude` 登录，终端输出登录链接，用 ClaudeWeb 内置浏览器打开并完成登录，之后聊天和终端都可直接使用。
- [ ] 确定 CLI 是否自动更新，以及 CLI 版本与 ClaudeWeb 的兼容检查。

## 资源和网络

- [ ] 取消现有项目对内存、Swap、CPU、进程及线程数量设置的专属配额。
- [ ] 检查 systemd 服务、父级 slice、任务数和进程限制的最终值，避免继承旧配额。
- [ ] 不人为设置偏小的 Node.js 堆上限或子进程配额。
- [ ] 项目和数据直接使用普通目录，不再创建固定大小的工作区 ext4 镜像。
- [ ] 不单独划分较小的磁盘容量或 inode 池。
- [ ] 不沿用现有小容量私有临时文件系统，正常使用 VPS 临时空间。
- [ ] 使用普通宿主机 IPv4 网络，使终端和浏览器能访问相同的本地服务。
- [ ] 不沿用当前只允许公网 TCP 80、443 和 DNS 的专用出口规则。
- [ ] 全局持久禁用 IPv6，配置前确认 IPv4 管理连接可用，重启后验证。
- [ ] 保留登录校验、管理凭据保护、浏览器内部沙箱和必要的输入检查。
- [ ] 停止任务、终端和图形会话时正确回收对应子进程，保留持久数据。
- [ ] 维护日志、临时文件和可再生缓存，不删除项目、聊天、记忆和登录数据。
- [ ] 说明资源仍受 VPS 套餐、宿主系统、文件系统及运行时本身上限约束。
- [ ] 内存耗尽时优先回收 Claude、终端和浏览器子进程，主服务最后被系统结束，网页保持可用。
- [ ] 不按安装时的内存写死数值：在服务商后台增加内存后，无需重装即可使用新增内存。
- [ ] 一键安装根据机器实际配置创建或调整 swap，安装后提供主动调整 swap 的命令。
- [ ] 磁盘使用情况与清理后续放进 ClaudeWeb 设置，目前不实现。

## 管理命令

- [ ] root 终端提供 `claudeweb` 管理命令：`help`、`status`、`logs`、`doctor`（收集诊断信息，不含密码和密钥）、`update`、`rollback`、`password`（查询与修改登录密码）、调整 swap、`uninstall`。不提供一键备份导出命令；更新失败回滚所需的内部备份由更新组件自动管理。
- [ ] `claudeweb uninstall` 只询问用户是否执行卸载：输入 `y` 执行，输入 `n` 停止；不提供导出操作。
